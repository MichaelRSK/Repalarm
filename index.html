    Setup

    About 10 minutes, one time. Do it on your iPhone.

    1. Let Safari use the camera.

      Open this page's menu by the address bar, go to Website Settings, and set Camera to Allow. Otherwise Safari asks every morning.

    2. Set up the Clock app.
      • On your wake alarm, turn Snooze off. Snoozing doesn't count as stopping. Don't put "RepAlarm" in its label.
      • Add backup alarms every 3 minutes after your wake time. For a 7:00 alarm: 7:03, 7:06, 7:09, 7:12, 7:15. Label each one RepAlarm Backup and leave them off.
      • Add one alarm about 45 minutes after wake time labeled RepAlarm Finish. Leave it off.
    3. Make a shortcut named RepAlarm Started.

      Runs after your first reps. It turns off the backups and turns on the finish-by alarm.

      Get All Alarms
      Repeat with Each item in Alarms If Repeat Item's Name contains RepAlarm Backup Toggle Alarm: Turn Off Repeat Item End If End Repeat
      Toggle Alarm: Turn On RepAlarm Finish
    4. Make a shortcut named RepAlarm Done.

      Runs when you finish or skip. It turns off everything RepAlarm turned on.

      Get All Alarms
      Repeat with Each item in Alarms If Repeat Item's Name contains RepAlarm Toggle Alarm: Turn Off Repeat Item End If End Repeat
    5. Add the automation.

      In Shortcuts, go to Automation, tap +, choose Alarm, pick your wake alarm, choose Is Stopped, and set it to Run Immediately. Then add:

      Get All Alarms
      Repeat with Each item in Alarms If Repeat Item's Name contains RepAlarm Backup Toggle Alarm: Turn On Repeat Item End If End Repeat
      Open URLs: the link below
    6. Test it.

      Use the test buttons in Settings, then set your wake alarm 2 minutes out and run the real thing with reps set low.
